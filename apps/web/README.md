# GrowthReceipt marketing workspace

The Next.js frontend for GrowthReceipt. It includes the daily workspace, products, campaigns, content review, calendar, verified results, experiments, integrations, settings, and the PayPal Sandbox checkout preview.

Run it from the repository root:

```bash
npm run dev:web
```

The interface uses Figtree, Lucide interface icons, and official provider marks from React Icons. It supports light and dark appearance, desktop navigation, and a mobile navigation drawer.

Start the API as well when testing verified revenue, recommendations, or checkout:

```bash
make dev-api
```
